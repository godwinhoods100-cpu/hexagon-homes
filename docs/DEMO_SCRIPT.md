# 5–10 minute demonstration script

1. **Home (1 minute):** Introduce the brand, responsive hero search, featured homes, lifestyle collections and service proposition.
2. **Discovery (1 minute):** Search for a city, combine type/bedroom/price filters, change sorting, clear filters and show the empty state.
3. **Property (1 minute):** Open a dynamic detail route, review gallery, specifications and amenities, save the property and submit a viewing request.
4. **Buyer account (1 minute):** Register/login, show role-aware navigation, favourites persistence and the account overview.
5. **Agent workflow (2 minutes):** Create an agent account, open the protected dashboard, add a listing, validate numeric fields and preview an uploaded image.
6. **API and security (1 minute):** Open Swagger, explain JWT refresh/logout, demonstrate a forbidden cross-owner update and the favourite uniqueness constraint.
7. **Quality and architecture (1 minute):** Show the ER diagram, automated test output, responsive mobile navigation and production build.
8. **Deployment (30 seconds):** Explain environment-based frontend/API URLs, hosted PostgreSQL and the need for persistent object storage.
